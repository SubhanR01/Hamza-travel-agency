FLUGPREISE AUF DER WEBSITE – Anleitung (Version 2: exakte Preise)
=================================================================

Was sich geändert hat
  - Es werden NUR noch Flüge für das genaue Datum angezeigt, das der Kunde wählt.
    Keine Preise von anderen Tagen mehr.
  - Gibt es keine Flüge/Preise, steht dort einfach: "No flights available for this date."

Zwei Modi im Preis-Dienst (flight-prices-worker.js)
  1) LIVE (exakte, aktuelle Preise direkt von den Airlines)  -> braucht ein Duffel-Konto
  2) DATEN (gespeicherte Preise von Travelpayouts, nur exaktes Datum) -> läuft schon

SCHRITT 1 – Neuen Code in Cloudflare einfügen (immer nötig)
  1. dash.cloudflare.com -> Workers & Pages -> hamza-flight -> "Edit code"
  2. Alles löschen, den Inhalt der neuen Datei flight-prices-worker.js einfügen, "Deploy".
  Ab jetzt: nur exakte Daten.

SCHRITT 2 – Echte Live-Preise mit Duffel (empfohlen)
  1. Konto anlegen: https://app.duffel.com/join
  2. Firmendaten ausfüllen. Für echte Preise den "Live mode" freischalten
     (Duffel prüft dein Unternehmen; Kosten nur bei Buchungen, ca. 3 US$ + 1 %).
  3. Developers -> Access tokens -> "Create token" (Live) -> kopieren.
  4. In Cloudflare beim Worker: Settings -> Variables and Secrets -> Add
       Typ: Secret   Name: DUFFEL_TOKEN   Wert: dein Duffel-Token
  5. Fertig. Die Website zeigt jetzt Live-Preise für genau das Datum, die Personenzahl und die Klasse.
  Hinweis: Duffel hat nicht jede Airline ab Kabul (z. B. Kam Air oder Ariana eventuell nicht).
  Dann steht dort "No flights available for this date." oder nur die verfügbaren Airlines.

Testen
  https://hamza-flight.ibogak66.workers.dev/?origin=KBL&destination=IST&depart=2026-11-10
  In der Antwort steht "mode":"live" (Duffel) oder "mode":"data" (Travelpayouts).

Sicherheit
  Wenn die Website online ist: ALLOWED_ORIGIN von * auf deine Website-Adresse ändern.
